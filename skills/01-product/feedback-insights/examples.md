# Примеры — feedback-insights

## Пример 1 — интерактивный режим

Пользователь загружает `sample_feedback.csv` и просит обработать данные.
Агент запускает скрипт в shell и показывает результат `insights.md`.

```bash
python3 scripts/analyze_feedback.py sample_feedback.csv --out insights.md
```

## Пример 2 — пайплайн-режим

Входной артефакт из `inputs` передаётся следующему скиллу через `manifest.json`.
Скилл пишет `manifest.json` с `outputs` и `suggested_next` для `report-builder`.

## Повторы и противоположные отзывы

**Запрос:** CSV с двумя строками: «Доставка доставка доставка доставка — отлично, рекомендую» и «Не нравится, ужасно».

**Ожидаемое поведение:** Два отдельных отзыва; слово «доставка» встречается 4 раза. Тональность считается по строкам, не по объединённому тексту; исходные метки и смысловые уточнения различимы.

## Синонимы и отрицания

«Приложение тормозит и зависает» → negative; «Отзывчивая поддержка, довольна» → positive; «Не понравилось, но удобный поиск» → mixed. «Без ошибок» не считается негативом, но отсутствие ошибок само по себе не доказывает положительный отзыв (unknown). Словарь использует ограниченные формы слов, а не понимание сарказма и контекста. Частоты остаются точными токенами без объединения синонимов.
