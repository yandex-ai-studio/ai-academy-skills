# Примеры — data-profiler

## Пример 1 — интерактивный режим

Пользователь загружает `sample_data.csv` и просит обработать данные.
Агент запускает скрипт в shell и показывает результат `report.md`.

```bash
python3 scripts/profile.py sample_data.csv --out report.md
```

## Пример 2 — пайплайн-режим

Входной артефакт из `inputs` передаётся следующему скиллу через `manifest.json`.
Скилл пишет `manifest.json` с `outputs` и `suggested_next` для `report-builder`.

## Дата и время

**Запрос:** Колонки 2026-09-01 / 02.09.2026 и 2026-09-01T12:30:00.

**Ожидаемое поведение:** Первая колонка date, вторая timestamp. Некорректные даты отмечены, типы перенесены из детерминированного отчёта.
