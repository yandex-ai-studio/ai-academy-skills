# Скрининг резюме под вакансию

## Запуск в AI Studio

Скрипт ниже — файл командной строки, не отдельный API-инструмент. Выбери `shell` из инструментов текущего ответа и передай ему команду `python3` с фактическим путём к скрипту и входным файлам, используя схему именно этого инструмента. Сначала прочитай этот SKILL.md и проверь пути через shell; затем выполни команду, проверь код завершения и прочитай результаты. Необходимость вычислений не создаёт новых инструментов. Если shell отсутствует, сообщи, что автоматический разбор не выполнен; текстовый разбор не выдавай за запуск скрипта. Если API завершил ответ ошибкой инструмента, сообщи об ошибке: такой ответ не подтверждает выполнение задачи.

```bash
python3 <skill-dir>/scripts/screen_resumes.py --job /app/job.txt --resumes /app/resume_a.txt /app/resume_b.txt --out-csv /app/resume_evidence.csv --report /app/resume_evidence.md
```

Сначала выдели профессиональные требования вакансии. Для сложной формулировки создай `/app/requirements.json` — массив строк — и передай `--requirements`; не добавляй требований от себя. Возраст, пол, семейное положение и другие нерелевантные признаки не используются.
Скрипт находит текстовые свидетельства, а не определяет компетентность. Содержательно проверь фрагменты: «не знаком с pandas» — отрицание опыта, не подтверждение навыка. Различай собственный опыт, желание изучить, отрицание, противоречия и отсутствие сведений. Если данных нет, сформулируй вопрос для интервью; это не отрицательная оценка человека.

Ответ строй по созданному CSV: для каждого резюме в исходном порядке покажи требование → точный фрагмент → статус из отчёта → вопрос для интервью. Статус «упоминание — проверить содержание и уровень» означает только наличие текста; он не превращается в «подтверждено» при пересказе. Если содержательная проверка выявила ошибку скрипта, отметь соответствующую строку «требует ручной проверки» и объясни расхождение цитатой.

Заверши общими ограничениями и ссылками на артефакты. Относительная пригодность кандидатов не входит в результат: не ранжируй, не начисляй баллы, не агрегируй число упоминаний в покрытие требований, не формируй автоматический шортлист и не принимай решение об отказе. Если пользователь просит рейтинг, предложи таблицу свидетельств для ручного решения. Сопоставление навыка с вариантом его написания не является проверкой стажа, глубины владения или соответствия всей вакансии.

Словарь объединяет варианты написания технологий, но не смежные навыки. Планы обучения отмечаются отдельно от упоминаний опыта. Произвольный текст и область отрицания всё равно требуют проверки по цитате.

## Данные и выполнение

Работай с текстом пользователя и загруженными файлами. Доступ к CRM, почте, 1С и другим корпоративным системам не требуется и не подразумевается.
Найди фактические файлы в контейнере; пути из примеров замени на реальные. Путь к скрипту определяется относительно прочитанного `SKILL.md`, а рабочие копии и результаты сохраняй отдельно в `/app` или `/tmp`.
Сначала посмотри заголовки и несколько строк. Если структура отличается, используй параметры сопоставления или подготовь нормализованную копию, показав соответствие полей. Не заменяй отсутствующие или нераспознанные значения нулями.
CSV читается как UTF-8, XLSX — локальным openpyxl из комплекта. Старый XLS требует экспорта в XLSX/CSV; смена расширения не конвертирует файл. Если вложение недоступно, сообщи, какой файл не найден; не анализируй вымышленные данные.
После запуска прочитай созданные файлы, сверь числа с входом и выдай краткий результат со ссылками на существующие артефакты. `manifest.json` содержит метрики и статус для следующего шага.
