# Примеры — resume-screener

## Отрицание опыта

**Запрос:** Вакансия требует pandas и SQL. Резюме: «С pandas не знаком. Использовал SQL для отчётности».

**Ожидаемое поведение:** Для pandas показать отрицание, для SQL — фрагмент опыта и вопрос для интервью. Без rank, score, сортировки по пригодности и автоматического отказа.

## Алиасы и границы свидетельств

JS ↔ JavaScript, Postgres ↔ PostgreSQL, Эксель ↔ Excel, Power BI ↔ PowerBI, 1С ↔ 1C, C sharp ↔ C#. Это варианты написания, а не вывод о смежных навыках: NoSQL не подтверждает SQL, Python не подтверждает pandas. «С SQL не работал, Python использовал» даёт раздельные свидетельства; «Планирую изучить Python» — план, не опыт. Сопоставление не проверяет требуемый стаж или владение всем стеком; это вопросы интервью.
