# Примеры — bank-statement-parser

## Пример 1 — интерактивный режим

Пользователь загружает `sample_statement.csv` и просит обработать данные.
Агент запускает скрипт в shell и показывает результат `categorized.csv`.

```bash
python3 scripts/parse_statement.py sample_statement.csv --out-csv categorized.csv --report reconciliation.md
```

## Пример 2 — пайплайн-режим

Входной артефакт из `inputs` передаётся следующему скиллу через `manifest.json`.
Скилл пишет `manifest.json` с `outputs` и `suggested_next` для `report-builder`.

## Русские заголовки и десятичная запятая

**Запрос:** CSV: «Дата операции;Назначение платежа;Сумма операции;Категория». Строки с «1 234,50» и заданной категорией.

**Ожидаемое поведение:** Распознать заголовки независимо от регистра, сохранить категорию и сумму 1234.50; непонятная сумма вызывает диагностику, не ноль.

## Профили и свои категории

Личная выписка: `python3 <skill-dir>/scripts/parse_statement.py /app/statement.csv --profile personal --rules /app/rules.json`. Скопируй пример JSON и оставь только согласованные с пользователем правила. «Перевод по СБП» без назначения остаётся для уточнения. «Перевод заработной платы» при поступлении в personal — доход от работы; при списании в business — зарплата сотрудникам. «Yandex» без уточнения сервиса не означает ни подписку, ни такси.
