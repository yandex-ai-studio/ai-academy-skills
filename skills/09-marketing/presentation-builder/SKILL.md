# Презентации

Создай законченный PPTX с ясной структурой и спокойным оформлением. Работай на языке пользователя.

## Содержание и оформление

- Определи аудиторию, цель и главный вывод из запроса. Уточняй только то, без чего нельзя содержательно продолжить. Если объём не указан, обычно достаточно 6–9 слайдов; короткий материал не растягивай.
- Сформулируй заголовки по существу: «Время ответа сократилось до 8 минут» вместо «Ключевые инсайты». Один слайд — один основной тезис. Не добавляй шаблонные вступления, лозунги и слайд «Спасибо» без необходимости.
- Сохраняй значения, единицы, периоды и оговорки из исходных данных. Заявления компании атрибутируй. Отсутствующие данные не заменяй придуманными. Демонстрационные числа обозначай как пример. Дату указывай только из запроса или проверенного системного времени.
- По умолчанию используй тему `paper`: тёплый светлый фон, графитовый текст, приглушённый синий акцент. Альтернативы — `sage` и `stone`. Цвета бренда применяй, когда пользователь их предоставил. Тёмный фон допустим по явной просьбе пользователя.
- Чередуй подходящие по смыслу макеты: тезис, числа, диаграмма, сравнение, таблица, последовательность. Не превращай каждый слайд в список или набор карточек.
- Изображение добавляй, если оно что-то объясняет: фотография объекта, продукта, схема или скриншот. Используй предоставленные изображения либо проверенные доступные источники. Без подходящего изображения сделай текстовый или числовой слайд. Не добавляй декоративные абстракции и текст поверх пёстрой картинки.
- Для чисел используй редактируемые диаграммы и таблицы. Укажи единицу и источник; столбцы сравнивай от нуля. На круговой диаграмме показывай только части одного целого. Длинные подписи сокращай без потери смысла; полные определения можно вынести в заметки.

## Сборка

Скрипты находятся в `scripts/` рядом с этим `SKILL.md`, темы и пример — в `assets/`. Обозначь абсолютный путь к этой папке как `SKILL_DIR`. Команды и Python запускай через доступный инструмент командной строки по его объявленной схеме.

1. Проверь среду:
   ```sh
   python3 "$SKILL_DIR/scripts/doctor.py"
   ```
   Если не хватает Python-библиотек, установи их командой `python3 -m pip install -r "$SKILL_DIR/requirements.txt"`. При недоступной установке сообщи, что сборка заблокирована; не выдавай текст за готовый файл.
2. Прочитай [формат спецификации](references/spec.md). Создай рабочую папку в доступном для записи каталоге и запиши `spec.json`. В AI Studio сохраняй итоговые файлы в `/app/output/`: они доступны через API файлов контейнера. Структурный пример: [assets/example.json](assets/example.json). Подготовь содержание под задачу пользователя, не копируй тему примера.
3. Проверь спецификацию и собери файл:
   ```sh
   python3 "$SKILL_DIR/scripts/builder.py" /absolute/work/spec.json --lint-only
   python3 "$SKILL_DIR/scripts/builder.py" /absolute/work/spec.json --output-dir /absolute/work/output
   ```
   В командах замени примерные пути на реальные. Локальные пути изображений в JSON считаются относительно `spec.json`. Используй собранный скрипт; не переписывай его для каждой презентации.
4. Если содержимое не помещается, сократи формулировку, выбери более подходящий макет или раздели слайд. Сохраняй все существенные данные. Повтори сборку после исправления. Скрипт проверяет размещение до сохранения окончательного файла.
5. Выполни проверку готового файла:
   ```sh
   python3 "$SKILL_DIR/scripts/validate_deck.py" /absolute/work/output/deck.pptx --strict
   ```
   Если `doctor.py` показал `render_available: true`, создай превью:
   ```sh
   python3 "$SKILL_DIR/scripts/render_deck.py" /absolute/work/output/deck.pptx --output-dir /absolute/work/preview --contact-sheet
   ```
   Просмотри PNG через доступный просмотр изображений: заголовки, переносы, подписи осей, таблицы, кадрирование. Исправь заметные дефекты и повтори сборку. Если рендер или просмотр недоступен, не утверждай, что внешний вид проверен.

## Результат

Убедись, что PPTX существует и содержит ожидаемое число слайдов. Передай файл через механизм файловых вложений текущей среды. Используй только ссылку, фактически возвращённую средой; путь внутри контейнера не является публичной ссылкой. Если среда не поддерживает выдачу вложений, сообщи точный путь к созданному файлу и это ограничение.

В ответе укажи файл, число слайдов и только существенные ограничения; обычно достаточно 2–3 предложений. В самой презентации оставь содержание задачи, без пояснений о работе инструментов.
