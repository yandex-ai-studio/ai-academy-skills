# Формат spec.json

UTF-8 JSON. Верхний уровень: `filename` (имя PPTX), `theme` (по умолчанию `paper`), `slides` (непустой массив). Формат слайдов — 16:9. Текст, таблицы и диаграммы редактируются в PowerPoint.

```json
{
  "filename": "report.pptx",
  "theme": "paper",
  "slides": [
    {"type": "title", "title": "Итоги пилота", "subtitle": "Сентябрь 2026"},
    {"type": "chart", "title": "Время ответа снизилось", "chart_type": "column",
     "categories": ["До пилота", "После пилота"],
     "series": [{"name": "Время ответа", "values": [14, 8]}],
     "unit": "Минуты, медиана", "source": "Демонстрационные данные"}
  ]
}
```

## Макеты

У каждого слайда есть `type`. Общие необязательные поля: `source` (короткая строка внизу) и `notes` (заметки докладчика). Все текстовые поля — строки, а не Markdown. Символ `\n` задаёт перенос. Неподдерживаемые поля вызывают ошибку.

| type | Обязательные поля | Необязательные поля |
|---|---|---|
| `title` | `title` | `subtitle`, `kicker`, `meta`, изображение |
| `section` | `title` | `subtitle`, `number`, изображение |
| `statement` | `title` | `body`, `eyebrow`, `dark` (по умолчанию false) |
| `bullets` | `title`, `bullets` | `lead`, `eyebrow` |
| `image` | `title`, изображение | `body`, `body_bold`, `bullets`, `image_side`, `eyebrow` |
| `metrics` | `title`, `metrics` | `eyebrow` |
| `chart` | `title`, `chart_type`, `categories`, `series` | `unit`, `insight`, `insight_label`, `eyebrow` |
| `comparison` | `title`, `left`, `right` | `eyebrow` |
| `timeline` | `title`, `steps` | `eyebrow` |
| `process` | `title`, `steps` | `eyebrow` |
| `quote` | `quote` | `attribution`, `role`, изображение |
| `table` | `title`, `columns`, `rows` | `column_widths`, `highlight_row`, `numeric_align`, `eyebrow` |
| `summary` | `title`, `takeaway`, `actions` | `eyebrow` |
| `closing` | `title` | `subtitle`, `contact`, изображение |

`eyebrow` — небольшая надпись над заголовком. На обложке для этого есть `kicker`.

### Текст и списки

- `bullets`: 1–5 непустых строк; в макете `image` — до 4.
- `actions`: 1–4 строки.
- `metrics`: 2–4 объекта `{"value":"−43%","label":"Время ответа","detail":"14 → 8 минут"}`. `value` — число или короткая строка; `detail` необязателен. Необязательный `color`: `#RRGGBB`.
- `left` / `right`: `{"heading":"До пилота","items":["Ручное распределение","Единая очередь"],"lead":""}`. До 4 пунктов, `lead` необязателен.
- `steps`: 2–5 объектов `{"label":"01","title":"Подготовка","detail":"Согласовать критерии"}`. `label` и `detail` необязательны. Название короткое, обычно 2–4 слова.

Ориентиры: заголовок содержательного слайда — до 70–90 знаков, на обложке — до 110; пункт — 1–2 строки, источник — одна строка. Это не гарантии вместимости: она зависит от макета и ширины букв. Проверка сборки останавливает переполнение. Подробности можно перенести в `notes`, но не скрывать там ключевые выводы.

### Диаграммы

`chart_type`: `column`, `bar`, `line`, `pie`. `categories`: 1–14 коротких строк. `series`: 1–6 объектов `{"name":"Показатель","values":[10,20]}`. Число значений равно числу категорий. Только конечные числа, без `%` и единиц внутри массива. Пропуск не заменяй нулём.

Для `pie`: одна серия, до 6 категорий, неотрицательные значения с положительной суммой. Для `column` и `bar` нулевое основание задаётся автоматически. Поле `unit` поясняет масштаб. `insight` добавляет справа короткий вывод и уменьшает ширину диаграммы. Для длинных названий выбирай `bar`; для 10–14 категорий обычно удобнее `line`. Если подписи становятся тесными, раздели данные по слайдам.

### Таблицы

`columns`: 1–6 названий. `rows`: 1–7 строк одинаковой длины; ячейка — текст или конечное число. `column_widths`: положительные относительные веса, например `[3, 1, 1]`. `highlight_row`: индекс строки начиная с 0. `numeric_align`: `right` (по умолчанию), `left` или `center`; применяется к числовым ячейкам после первого столбца.

Заголовки должны помещаться в одну строку. Для длинных описаний расширь столбец и уменьши число строк. Крупную таблицу раздели: шрифт нельзя уменьшать до нечитаемого.

### Изображения

Одно из полей: `image` (локальный путь) или `image_url` (проверенный HTTP(S) URL). Локальные файлы предпочтительны. PNG и JPEG встраиваются в PPTX, удалённый файл проверяется перед вставкой. Ссылки на HTML-страницы изображениями не считаются.

`image_side`: `right` (по умолчанию) или `left`, только для макета `image`. `focal_x` / `focal_y`: числа от 0 до 1, точка кадрирования, по умолчанию 0.5; поддерживаются макетами `title` и `image`. Изображение заполняет свою рамку с сохранением пропорций. Для графика или схемы, которую нельзя обрезать, предпочти встроенный макет либо предварительно добавь поля к изображению.

### Темы

`paper` — приглушённый синий, `sage` — зелёный, `stone` — коричневый. Все три темы светлые. Для предоставленного фирменного стиля:

```json
{"theme":{"base":"paper","overrides":{"accent":"#52667A","font_headline":"Arial","font_body":"Arial"}}}
```

Допустимые токены перечислены в `assets/themes.json`. Используй установленные шрифты: гарнитуры в PPTX не встраиваются. Цвет текста должен заметно отличаться от фона. Не перекрашивай каждую цифру в отдельный яркий цвет.
