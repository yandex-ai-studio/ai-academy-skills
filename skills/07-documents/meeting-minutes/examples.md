# Примеры — meeting-minutes

## Пример 1 — интерактивный режим

Пользователь загружает `sample_meeting.txt` и просит обработать данные.
Агент запускает скрипт в shell и показывает результат `meeting_minutes.md`.

```bash
python3 scripts/parse_meeting.py sample_meeting.txt --out meeting_minutes.md --out-csv action_items.csv
```

## Пример 2 — пайплайн-режим

Входной артефакт из `inputs` передаётся следующему скиллу через `manifest.json`.
Скилл пишет `manifest.json` с `outputs` и `suggested_next` для `report-builder`.

## Сплошной абзац

**Запрос:** «Решили запустить пилот. Анна подготовит смету до 20.09.2026. Борис: предлагаю поменять поставщика. Как измерим результат?»

**Ожидаемое поведение:** Одно решение, задача Анне с указанным сроком и открытый вопрос. Предложение Бориса не становится решением.

## Формулировки поручений

«Поручение: собрать оценки, owner: Анна, срок: завтра» и «Пётр организует встречу к пятнице» — задачи. Сохрани относительный срок буквально; без даты встречи не вычисляй календарную дату. «Утвердили план» — решение, «Анна: план выглядит удачным» — реплика, «Иван: предлагаю проверить гипотезу» — предложение, не назначенная задача. Одинаковые задачи с разными ответственными не объединяются.
